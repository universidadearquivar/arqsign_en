# 🗑️ Deleted

In the Deleted menu, all documents deleted by the user are displayed. Documents that have been completed, canceled, or merely created can be deleted.

{% hint style="warning" %}
<mark style="color:orange;">**It is not possible to view the document on the Deleted screen. To view the file, it is necessary to restore the document and access it from its original inbox, which can be the**</mark> [<mark style="color:blue;">**Inbox**</mark>](inbox.md) <mark style="color:orange;">**or the**</mark> [<mark style="color:blue;">**Sent**</mark>](sent.md) <mark style="color:orange;">**folder.**</mark>
{% endhint %}

## Columns of the Main Screen – Deleted&#x20;

<figure><img src="../.gitbook/assets/02 (2).png" alt=""><figcaption><p>Click on the image to enlarge.</p></figcaption></figure>

**Document Name Column:** This column displays the document name and the signatory's name. If there are multiple signatories, the name of the first signatory is shown, along with the number of additional people who need to sign.

**Responsible Column:** This column shows the name and email of the person who sent the document (sender).

**Status Column:** The possible statuses for a document are: "Completed" (all participants have signed the document), "Canceled" (the document's sending was canceled, and the signing process was interrupted), and "Created" (the document was created on the platform, but its configuration and sending to recipients have not been completed). Hovering over the status will display information about which signatories still have pending signatures and which have completed them, along with the data of those signatories. It will also show the security code sent to recipients (if applicable).

<figure><img src="../.gitbook/assets/03 (1) (1) (1) (1) (1).png" alt=""><figcaption><p>Click on the image to enlarge.</p></figcaption></figure>

**Column Size:** This column displays the file size of the document.

**Column Folder:** In this column, the directory folder where the document is stored is shown. If the user does not have permission to access the folder, "No folder" will be displayed.

**Column Completed:** Information about the date and time when the document signing process was completed. If it has not been completed yet, this column will be blank.

**Column Deleted:** Information about the date and time when the document was deleted.

**Column Actions:** This column displays action buttons related to the document. The priority action for execution, according to the user's profile and document status, will always be displayed in this button.

<figure><img src="../.gitbook/assets/05 (1) (1) (1) (1) (1).png" alt=""><figcaption><p>Click on the image to enlarge.</p></figcaption></figure>

**Filter Bar:** It allows locating one or more documents using the available search filters. On the Deleted Items screen, the search can be performed by the document name, the responsible party's name, the names of the signatories, the document status, the folder where the document is hosted, or the document deletion date.&#x20;

<figure><img src="../.gitbook/assets/04 (1) (1) (1) (1) (1).png" alt=""><figcaption><p>Click on the image to enlarge.</p></figcaption></figure>

## Batch Action Buttons - Deleted Items&#x20;

Users can efficiently manage multiple documents within the Deleted Items screen by selecting them through checkboxes and performing batch actions.

**Restore:** The sole batch action available on the Deleted Items screen is to restore documents, reinstating them to their original mailbox. It's essential to note that only documents deleted within the past year can be restored.

<figure><img src="../.gitbook/assets/07 (1) (1) (1) (1).png" alt=""><figcaption><p>Click on the image to enlarge.</p></figcaption></figure>

{% hint style="warning" %}
<mark style="color:orange;">**Documents marked as "Concluded" will return to the Inbox if the user is a participant in the signature process, or to the Sent Items if they are the document owner.**</mark>&#x20;

<mark style="color:orange;">**Documents with the "Cancelled" status always return to the Sent Items, as they are owned by the user.**</mark>&#x20;
{% endhint %}

{% hint style="danger" %}
<mark style="color:red;">**Documents with the "Created" status cannot be restored.**</mark>&#x20;
{% endhint %}

***

## Individual Action Buttons - Deleted Items&#x20;

<figure><img src="../.gitbook/assets/05 (2).png" alt=""><figcaption><p>Click on the image to enlarge.</p></figcaption></figure>

**Restore:** Clicking this option reinstates the document to its original mailbox prior to deletion. Only documents deleted within the past year can be restored.

{% hint style="warning" %}
<mark style="color:orange;">**Documents with the "Concluded" status will return to the Inbox if the user is a participant in the signature process, or to the Sent Items if they are the document owner.**</mark>&#x20;

<mark style="color:orange;">**Documents with the "Cancelled" status always return to the Sent Items, as they are owned by the user.**</mark>&#x20;
{% endhint %}

{% hint style="danger" %}
<mark style="color:red;">**Documents with the "Created" status cannot be restored.**</mark>&#x20;
{% endhint %}

**Download File:** This action allows users to swiftly download the document for offline access or archival purposes, enhancing accessibility and flexibility.

**History:** This feature enables users to access comprehensive information regarding the document and its associated events. Users can review the document's history, including all relevant actions and changes. Additionally, users have the option to download the original files of the document before signatures were completed.

{% hint style="warning" %}
<mark style="color:orange;">**This functionality is exclusively available for documents with the "Concluded" status.**</mark>
{% endhint %}
