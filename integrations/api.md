# 🟪 API

In the API menu, the client has access to the keys required for managing and controlling the requests made through the integration API.

<figure><img src="../.gitbook/assets/image (206).png" alt=""><figcaption></figcaption></figure>

## AppKey

To integrate the platform with other tools via API, an Access Key is required, which the user can obtain by clicking on "Generate Key." The generated key will be displayed in the "API AppKey" field.

{% hint style="danger" %}
<mark style="color:red;">**Whenever a new access key is generated, all integrations using the previous key will be deconfigured. It is recommended to exercise caution when creating new access keys.**</mark>
{% endhint %}

## SubscriptionKey

These are access keys created to provide additional security for the exchange of information between external platforms and ArqSign.

**Key 1:** When the client does not yet have a generated key, the field will be blank. When the client has a key, Key 1 will be automatically generated by the system.

**Key 2:** Similarly, when the client has not yet generated a key, the field will be blank. When the client has a key, Key 2 will be automatically generated by the system.

By **default**, the system will always generate a "**pair**" of **keys.** The client can use either **one, or they** can **be used in a rotating manner.** In other words, with each call, the user may use one, or in cases where the integration occurs with third parties, the client uses one and the third party uses another.

Once the key is generated, it must be included in the HEADER of requests for authorization.

By clicking "Generate Key Pair," a validation message will appear on the screen confirming the action.

<figure><img src="../.gitbook/assets/image (207).png" alt="" width="563"><figcaption></figcaption></figure>

{% hint style="danger" %}
<mark style="color:red;">**If, after regenerating the keys, the user does not update them in the search parameters of the existing integration, the API calls to ArqSign will stop functioning.**</mark>
{% endhint %}

To **regenerate the key pai**r, use the "**Generate Key Pair**" button. To **regenerate only one of the keys**, use the "**Regenerate Key**" icon, considering either Key 1 or Key 2.

<figure><img src="../.gitbook/assets/image (208).png" alt=""><figcaption></figcaption></figure>
