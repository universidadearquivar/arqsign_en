# 🔳 Library for Postman Testing

Access or download the <mark style="color:orange;">**Postman**</mark> application to simulate the requests that can be made to the ArqSign API.

Access: [<mark style="color:orange;">**https://www.postman.com/downloads/**</mark>](https://www.postman.com/downloads/)

Download the library "[<mark style="color:blue;">**Exemplos API ArqSign.**</mark>](https://view.genially.com/66e45805210207c31eb0b501)"

This library provides examples of how requests should be made to the ArqSign API.

* <mark style="color:yellow;">**POST**</mark> Send Process - With Automatic Page
* <mark style="color:yellow;">**POST**</mark> Send Process - With Manual Page
* <mark style="color:green;">**GET**</mark> Get Process Status
* <mark style="color:green;">**GET**</mark> Get Process Data
* <mark style="color:green;">**GET**</mark> Get Signatory Data
* <mark style="color:purple;">**PATCH**</mark> Cancel Process
* <mark style="color:purple;">**PATCH**</mark> Edit and Resend Process - With Edit
* <mark style="color:purple;">**PATCH**</mark> Edit and Resend Process - Without Edit

To use them, import the library into Postman:
