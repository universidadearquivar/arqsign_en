# ✔️ 4.1.GET/api/v1/conta/papeis-signatarios

## **Request**

The request is not applicable as the validation is conducted through the AppKey.

## **Validations**

### **General Validations**

1. To authenticate with the ArqSign API, the user must provide the AppKey of the account from which they are retrieving the signatories' documents.
2. Only accounts with an Active status can retrieve the signatories' documents via the ArqSign integration.

## **Validation Responses**

### **Error: 400 - Bad Request**

This error is returned when it is not possible to interpret the request and/or the server attempts to process the request, but one or more parameters are invalid. For example, this may occur due to incorrectly formatted resources or an attempt to make a request with missing data. Information regarding the request is provided in the response body and includes an error code and an error message.

**a**. **Required Item:** This message is displayed in singular or plural when one or more required items have not been sent in the API call.

> **Message:** The listed item(s) is/are required: "names of the items separated by commas."

**b. Incorrect Format:** This message is displayed in singular or plural when one or more items have been sent with an incorrect format.

> **Message:** The listed item(s) has/have an incorrect format: "names of the items separated by commas."

c. **Nonexistent IDs:** This message is displayed in singular or plural when one or more IDs sent do not exist.

> **Message:** The listed ID(s) do not exist: "names of the items that are table IDs, separated by commas."

d. **Some Parameter is Incorrect or Nonexistent:** This message is displayed when the call is made with a misspelled parameter or when information that does not exist within the method is sent.

> **Message:** Some parameter is incorrect or nonexistent.

### **Error: 401 - Unauthorized**

This error is returned when the authentication key for the ArqSign API is incorrect or has not been provided correctly.

### **Error: 404 - Not Found**

This error is returned when the requested resource or endpoint has not been located.

### **Error: 500 - Server Error**

This error is returned when:

* An internal server error occurs;
* A failure in the ArqSign platform occurs;
* The JSON format is incorrect.

## **Successful Response**

Status 200 - Success

The system returns the signatories' documents for the account.

### **Signatory Document Details**

1. **ID**\
   The system returns the ID of the signatory document.
2. **Name**\
   The system returns the name of the signatory document.
3. **Standard**\
   The system returns information indicating whether the signatory document is standard or not (true or false).
