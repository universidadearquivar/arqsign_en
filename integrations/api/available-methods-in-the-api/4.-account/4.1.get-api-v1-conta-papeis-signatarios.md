# ✔️ 4.1.GET/api/v1/conta/papeis-signatarios

## Request

The request does not apply because the validation is done via the AppKey.

## Validations

### General Validations

1. To authenticate on the ArqSign API, the user must provide the AppKey of the account from which the signer roles data is being fetched.
2. Only accounts with an Active status can fetch signer roles data from the account via the ArqSign integration.

This error is returned when the API authentication key for ArqSign is incorrect or has not been provided correctly.

### Error: 404 - Not Found

This error is returned when the requested resource or endpoint is not found.

### Error: 500 - Server Error

This error is returned when:

* An internal server error occurs
* A failure happens on the ArqSign platform
* The JSON format is incorrect.

## Success Return

Status 200 - Success

The system returns the signer roles of the account.

### Signer Role Data

**1 - id**

The system returns the ID of the signer role.

**2 - nome**

The system returns the name of the signer role.

**3 - padrao**

The system returns whether the signer role is default or not (true or false).
