# ✔️ 4.3.GET/api/v1/conta/dados-assinatura

## Validations

### General Validations

The user must provide the AppKey and SubscriptionKey (SubscriptionKey1 or SubscriptionKey2) of the account.

## Return Validations

### Error: 400 - Bad Request

This error is returned when the request cannot be interpreted, and/or the server attempts to process the request but a parameter in the request is invalid, for example, a malformed resource or a request with missing data. Information about the request is provided in the response body and includes an error code and error message.

**a- Mandatory Item:** This message is displayed in singular or plural when one or more mandatory items are not provided in the API call.

> **Message:** The following mandatory item(s) were not provided: "_item names separated by commas_."

**b- Incorrect Format:** This message is displayed in singular or plural when one or more items are provided in an incorrect format.

> **Message:** The following item(s) have an incorrect format: "_item names separated by commas_."

**c- Nonexistent IDs:** This message is displayed in singular or plural when one or more provided IDs do not exist.

> **Message:** The following ID(s) do not exist: "_names of the items corresponding to table IDs, separated by commas_."

**d- Incorrect or Nonexistent Parameter:** This message is displayed when the API call includes a misspelled parameter or sends information that does not exist in the method.

> **Message:** A parameter is incorrect or does not exist.

### Error: 401 – Unauthorized

This error is returned when the ArqSign API authentication key is incorrect or was not provided correctly.

### Error: 404 - Not Found

This error is returned when the requested resource or endpoint is not found.

### Error: 500 - Server Error

This error is returned when:

* An internal server error occurs.
* A failure occurs on the ArqSign platform.
* The JSON format is incorrect.

## Successful Response

Status 200 - Success&#x20;

The system should return the data for the specified account.

### Account Data

**Account**

The system returns the account data identified via AppKey.

> **id**\
> The system returns the account id of the provided AppKey.
>
> **nome**\
> The system returns the name of the account.
>
> **status**\
> The system returns the account status: Active, Inactive, Blocked, and Pending.\
> It returns the status according to the account's language.

**plano**

The system returns the plan data of the last subscription of the account.

> **id**\
> The system returns the id of the last subscription's plan of the account.
>
> **tipoPlano**\
> The system returns the type of the plan of the account's last subscription.\
> C = Corporate\
> P = Professional/Business\
> G = Free
>
> **nome**\
> The system returns the name of the plan of the account's last subscription, according to the account's language.
>
> **periodo**\
> The system returns the period of the last subscription's plan of the account.
>
> **valor**\
> The system returns the value of the last subscription's plan of the account.

**assinatura**&#x20;

The system returns the last subscription of the account.

> **id**
>
> The system returns the id of the last subscription of the account.
>
> **inicioVigencia**
>
> The system returns the start period of the last subscription of the account.
>
> **fimVigencia**
>
> The system returns the end period of the last subscription of the account.
>
> **trial**
>
> The system returns whether the account's last subscription is in a trial period.
>
> **itens**
>
> The system returns the items of the account's last subscription.
>
> > **id**
> >
> > The system returns the id of the item in the account's last subscription.
> >
> > **nome**
> >
> > The system returns the name of the item in the account's last subscription.\
> > It returns the name according to the account's language.
> >
> > **saldo**
> >
> > It returns the current balance for the item in question.\
> > This balance includes the balance of the active subscription + the balance of the active additional item.\
> > If the account's last subscription is not active, the balance will be 0.
> >
> > **permiteExcedente**
> >
> > The system returns whether the item in the account's last subscription allows excess.
