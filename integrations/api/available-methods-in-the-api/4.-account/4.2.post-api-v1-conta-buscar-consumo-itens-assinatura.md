## Validations

### Specific Validations

**dataInicial**

> **Description**: Mandatory parameter specifying the start date for the reference of an item.
>
> **Format**: ISO date format <mark style="color:red;">(yyyy-mm-dd or mm-dd-yyyy)</mark>
>
> **Required**: <mark style="color:red;">Yes</mark>
>
> **Validation**:
>
> a- The system does not allow `dataInicial` to be greater than `dataFinal`.

**dataFinal**

> **Description**: Mandatory parameter specifying the end date for the reference of an item.
>
> **Format**: ISO date format <mark style="color:red;">(yyyy-mm-dd or mm-dd-yyyy)</mark>.
>
> **Required**: <mark style="color:red;">Yes</mark>
>
> **Validation**:
>
> a- The system does not allow `dataFinal` to be less than `dataInicial`.

**item**

> **Description**: Mandatory parameter specifying the desired item.
>
> **Format**: Tinyint -**`0 = All items; 1 = Sending; 2 = WhatsApp; 3 = SMS`**
>
> **Required**: Yes.
>
> **Validation**:
>
> a- Only the following numbers are accepted:
>
> * `0` to return all items used by the account (Sending, SMS, and WhatsApp).
> * `1` to return only the usage of the Sending item.
> * `2` to return only the usage of the WhatsApp item.
> * `3` to return only the usage of the SMS item.
>
> If a user sends a number outside this range, the response will return the message: **"Ids inexistente."**

### General Validations

1- The user must provide the account's AppKey and SubscriptionKey (SubscriptionKey1 or SubscriptionKey2).

2- Only accounts with _Active_ status can retrieve usage and consumption data via ArqSign integration.

3- The system limits the period between _**dataInicial**_ and _**dataFinal**_, allowing up to 1 year.

### Account Data

1. **id**

The system returns the account ID.

2. **nomeConta**

The system returns the name of the account.

3. **itens**

> **id**
>
> The system returns the ID of the item in question. Only the items requested in the request (parameter **item**) are returned:
>
> 1 = Envio (Send)
>
> 2 = WhatsApp
>
> 3 = SMS
>
> **nome**
>
> The system returns the name of the item in question, based on the account’s language.
>
> **quantidade**
>
> The system returns the usage quantity for the item in question within the period specified in the request.

        }
    ]
