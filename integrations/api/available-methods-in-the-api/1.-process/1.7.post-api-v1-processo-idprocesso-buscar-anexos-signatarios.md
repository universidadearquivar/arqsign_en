# ✔️ 1.7.POST/api/v1/processo/{idProcesso}/buscar-anexos-signatarios

This service allows you to search for the **attachments of signatories** by specifying **one or more specific signatories of the process.**

## Request

**Guidelines:**

When the required field is marked as "Yes" = Always required

When the required field is marked as "No" = Optional information

When the required field is marked as "Maybe" = In some cases, it will be required. To know these cases, refer to the description of the topic, according to the reference number in the table.

**Example Body Request**

```html
{
    "arquivoTipo": "byte",
    "signatarios": [
        "guid",
        "guid"
                ]
}
```

## Validations

### Specific Validations

The user must provide the IdProcesso for which they want to query the signatories' attachments.

The system will return the signatories' attachments in the format of either a download link or base64 of the file.

**arquivoTipo**

> **Description:** Required parameter specifying whether to return the **download link or the base64** of the signatory's attachment.
>
> **Format:** Byte - 1 = base64, 2 = Download link
>
> **Required:** <mark style="color:red;">Yes</mark>
>
>
>
> **Validation:**
>
> a- Only values 1 or 2 are allowed.
>
> * **Message:** The parameter **arquivoTipo** only accepts values 1 or 2.
> * When the **value 1** is sent in the **arquivoTipo** parameter, it means the system will return the signatories' attachments in base64 **format**.
> * When the **value 2** is sent in the **arquivoTipo** parameter, it means the system will **return the download link** for the signatories' attachments.

**Signatarios**

This part of the JSON is **optional**, and the user may specify one or more signatory IDs from the signing process to query their attachments, if any.

> **Description:** Parameter specifying one or more signatory IDs from the process.
>
> **Format:** Guid
>
> **Required:** <mark style="color:blue;">No</mark>
>
>
>
> **Validation:**\
> a- If **no signatory IDs are provided**, the system will **return all attachments (both public and private) for the signatories of the specified process**, according to the **arquivoTipo** parameter.
>
> b- If signatory IDs are provided, the system will validate if the signatories belong to the provided process.
>
> If at least one signatory ID belongs to the specified process, the system will return the attachments (public and private) for that signatory, if available.
>
> c- If the signatory in the process does not have attachments, the value **null** will be returned in the **anexos** object.

## General Validations

1. To authenticate with the ArqSign API, the user must provide the AppKey of the account that is querying the signatories' attachments of the process.
2. Only accounts with an **Active status** can query the signatories' attachments via the ArqSign integration.
3. The system validates that the **IdProcesso** belongs to the account associated with the provided AppKey.

### Attachments of the Process Signatories

**1- idSignatario**

The system returns the signatory's ID.

**2- nome**

The system returns the signatory's name.

**3- anexos**

The system returns the signatory's attachments, sorted by name.

> **3.1- id**
>
> The system returns the attachment ID of the signatory.
>
> **3.2- nome**
>
> The system returns the configuration name + the signatory's attachment name (with the extension).
>
> **3.3- arquivo**
>
> The system returns the signatory's attachment/file in base64 format when the arquivoTipo parameter has the value 1 (one).\
> The system returns the link to download the signatory's attachment/file when the arquivoTipo parameter has the value 2 (two).
