# ✔️ 1.8.GET/api/v1/processo/{idArquivoProcesso}/registro-assinaturas

This service allows retrieving the base64 of the signature record for a process file.

## Validations

### General Validations

1. The user must provide the AppKey and SubscriptionKey (SubscriptionKey1 or SubscriptionKey2) of the account.
2. Only accounts with an Active status can retrieve the signature record of a FileProcess via ArqSign integration.
3. The system only returns the signature record for **processes with a status other than "Created."**

## Return Validations

### Error: 400 - Bad Request

This error is returned when the request cannot be interpreted, or the server tries to process the request but one or more parameters are invalid, for example, a resource formatted incorrectly or a request with missing data. The request details are provided in the response body, including an error code and error message.

**a. Required Item:** This message is displayed in singular or plural when one or more required items have not been sent in the API call.

> **Message:** The following item(s) are required: "names of items separated by commas."

**b. Incorrect Format:** This message is displayed in singular or plural when one or more items are sent with an incorrect format.

> **Message:** The following item(s) are in the incorrect format: "names of items separated by commas."

**c. Non-existent Ids:** This message is displayed in singular or plural when one or more Ids sent do not exist.

> **Message:** The following Id(s) do not exist: "names of items that are table Ids, separated by commas."

**d. Incorrect or Non-existent Parameter:** This message is displayed when a call is made with a misspelled parameter or when an information that doesn't exist in the method is sent.

> **Message:** Some parameters are incorrect or non-existent.

### Error: 401 – Unauthorized

This error is returned when the ArqSign API authentication key is incorrect or was not provided correctly.

### Error: 404 - Not Found

This error is returned when the requested resource or endpoint could not be found.

### Error: 500 - Server Error

This error is returned when:

* An internal server error occurs.
* A failure occurs in the ArqSign platform.
* The JSON format is incorrect.

## Successful Return

Status 200 - Success&#x20;

The system returns the signature record file in base64 format for the provided idArquivoProcesso.

### Signature Record Data

1. **id**\
   The system returns the id of the process file that the signature record refers to.
2. **nome**\
   The system returns the name of the document that the signature record refers to, followed by the phrase “Signature Record.” Example: “Contract\_Signature Record.pdf”
3. **base64**\
   The system returns the base64 of the signature record.

### Return - Example Body Response

}
