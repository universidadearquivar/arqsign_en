* &#x20;When the required field is marked as "Yes" = Always required
* When the required field is marked as "No" = Optional information
* When the required field is marked as "Maybe" = In some cases, it will be required. To know these cases, refer to the description of the topic according to the line reference number in the table.

### Example Body Request

```
{
    "status": "byte"
}
```

## Validations

Specific Validations

**status**

> **Description:** Parameter indicating the status to be changed in the Webhook.
>
> **Format:** Byte - 1 = Active, 2 = Inactive
>
> **Required:** <mark style="color:red;">Yes</mark>
>
> **Validation:**
>
> a- Only values of 1 or 2 are allowed.
>
> b- When activating a webhook configuration, the system resets the attempt counts of the triggers, if any.

**General Validations**

Authentication

1- To authenticate in the ArqSign API, the user must provide the AppKey of the account that is changing the webhook configuration status.

2- Only accounts with Active status can change the webhook configuration status via ArqSign integration.

3- The system validates whether the provided **IdConfWebHook** belongs to the account of the **AppKey**.

Information about the request is provided in the response body, including an error code and a message.

**c- Non-existent Ids:** This message is displayed in singular or plural when one or more Ids sent do not exist.

**d- Some parameter is incorrect or non-existent:** This message is displayed when the request is made with a misspelled parameter or when a non-existent piece of information is sent.

> **Message:** Some parameter is incorrect or non-existent.

### Error: 401 – Unauthorized

This error is returned when

* The ArqSign API authentication key is incorrect or was not correctly provided.
* The account status is not Active.

### Error: 404 - Not Found

This error is returned when the requested resource or endpoint cannot be found.

### Error: 500 - Server Error

This error is returned when:

* An internal server error occurs;
* A failure occurs on the ArqSign platform;
* The parameter format is incorrect;
* The JSON format is incorrect.

## Success Return

When the webhook configuration status change is successfully executed, the system returns code 200 – OK.
