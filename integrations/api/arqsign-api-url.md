# 🔳 ArqSign API URL

To view the online API documentation of the ArqSign platform, visit: [**https://developers.arqsign.com/**](https://developers.arqsign.com/)

{% hint style="info" %}
<mark style="color:blue;">Before accessing the services from the provided URL, read the information in this integration manual to ensure a complete understanding of the requirements.</mark>
{% endhint %}

<figure><img src="../../.gitbook/assets/image (228).png" alt=""><figcaption></figcaption></figure>

When accessing the documentation URL, a list of available APIs is displayed. Clicking on an API reveals its details on the screen.

<figure><img src="../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>

On the left side of the screen, the list of available methods for the selected API is displayed.

<figure><img src="../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

By clicking on the method, its details are displayed on the right side of the screen.

<figure><img src="../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>

**Search operations:** Use this to search for a method within the selected API on the screen.

**Group by tag:** Use this to group the methods of the selected API.

**Try it:** Use this to test the method.

By clicking on the "Try it" option, the parameter and header fields are opened on the right side of the screen for input and testing.

<figure><img src="../../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure>

In the "headers" area, the "[SubscriptionKey](./#subscriptionkey)" and "[AppKey](./#appkey)" must be provided.
