# ✔️ 5.2.POST/api/v1/confwebhook

## Request

**Guidelines:**

* When the required field is marked as "Yes" = Always required
* When the required field is marked as "No" = Optional information
* When the required field is marked as "Maybe" = In some cases, it will be required. To know these cases, refer to the description of the topic, according to the reference number of the line in the table.

## Validations

### Specific Validations

> nome&#x20;
>
> Description: Parameter indicating the name of the Webhook.&#x20;
>
> Format: String Required: Yes&#x20;
>
> Validation:&#x20;
>
> a- The system validates the requirement and size of the String, allowing up to 150 characters for the name parameter.&#x20;
>
> b- The system does not allow registering a Webhook with the same name in the account in question.
