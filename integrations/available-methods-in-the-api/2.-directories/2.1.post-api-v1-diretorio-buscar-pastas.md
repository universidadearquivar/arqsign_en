# ✔️ 2.1.POST/api/v1/diretorio/buscar-pastas

This service allows retrieving the folder data of the account.

The user will have the option to search for:

* Full path of one or more folders;
* The children of a folder;
* The root folder and its first children.

## Request

**Guidelines:**

When the required field is marked as "Yes" = Always required

When the required field is marked as "No" = Optional information

When the required field is marked as "Maybe" = It will be required in some cases. To know these cases, refer to the specific validation description section.

### Example Body Request

```
{
   "buscarPor": "tinyint",//1 - Caminho Completo, 2 = Filhos, 3 = Pasta Raiz 
   "ativas": "bit",//1 – true, 0 = false
   "pastas": [
    "guid",
    "guid",
    "guid",
    "guid"
     ]
}
```

## Validations

### Specific Validations

**buscarPor**

> **Description:** Required parameter indicating the type of search to be executed.
>
> **Format:** Bit: 1 - Full Path, 2 - Children, 3 - Root Folder
>
> **Required:** <mark style="color:red;">Yes</mark>
>
> **Validation:**
>
> a- Only values 1, 2, or 3 are allowed.

**ativas**

> **Description:** Parameter indicating whether the search should return only active folders or all folders.
>
> **Format:** Bit: 1 - True, 0 - False
>
> **Required:** <mark style="color:blue;">No</mark>
>
> **Validation:**
>
> a- If this parameter is sent as **true**, the system returns **only active folders**, considering the other search parameters.
>
> b- If this parameter is sent as **false**, the system returns both **active and logically deleted folders**, considering the other search parameters.
>
> c- If this parameter is **not** sent or is sent as **null**, the system considers it as **false** and returns both **active and logically deleted folders**, considering the other search parameters.

**pastas**

> **Description:** Parameter indicating the folders to be queried. This information is necessary when searching by the full path of one or more folders or when searching for the children of a folder.
>
> **Format:** Guid
>
> **Required:** <mark style="color:red;">Yes, when buscarPor is equal to 1 or 2</mark>
>
> **Validation:**\
> a- It is not required to provide folders when **buscarPor** is equal to 3. The system disregards this parameter when **buscarPor** is equal to 3.
>
> b- The system requires a folder ID when **buscarPo**r is equal to 1 or 2.
>
> c- Only one folder ID is allowed when **buscarPo**r is equal to 2.
>
> d- One or more folder IDs are allowed when **buscarPor** is equal to 1.
>
> e- When a folder ID is provided, the system validates whether the **idPasta** belongs to the account.

### General Validations

1- The user must provide the AppKey of the account that is querying the folder data.

2- Only accounts with an Active status can query folder data via the ArqSign integration.

### Folder Data

**1 - id**

The system returns the folder ID.

**2 - nome**

The system returns the folder name.

**3 - caminhoCompleto**

The system **returns the full path of the specified folders.**

Example: Arquivar|Administração|Contratos

**4 - status**

The system returns the folder status: "**Ativa**" or "**Excluída**"

**Ativa** = Folder is not logically deleted.

**Excluída** = Folder is logically deleted.

**5 - filhos**

When the **parameter buscarPor is equal to 1 (Full Path)**, the system does **not return the children of the specified folders.**

When the **parameter buscarPor is equal to 2 (Children)**, the system **returns the children of the specified folder**, sorted alphabetically by name.

When the **parameter buscarPor is equal to 3 (Root Folder)**, the system r**eturns data for the root folder and its first children,** sorted alphabetically by name.

**5.1 - id**

The system returns the ID of the child folder.

**5.2 - nome**

The system returns the name of the child folder.

**5.3 - caminhoCompleto**

The system returns the full path of the child folder.

Example: Arquivar|Administração|Contratos

**5.4 - status**

The system returns the status of the child folder: "**Ativa**" or "**Excluída**"

**Ativa** = Folder is not logically deleted.

**Excluída** = Folder is logically deleted.

**5.5 - possuiFilhos**

The system indicates whether the child folder has children or not.
