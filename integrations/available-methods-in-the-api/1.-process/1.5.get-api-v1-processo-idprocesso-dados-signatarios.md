# ✔️ 1.5.GET/api/v1/processo/{idprocesso}/dados-signatarios

The purpose of this method is to allow the user to retrieve the data of signatories who are set to sign electronically in a signature process.

In this method, the user will send us the Process ID, and we will return a complete JSON with the process and signatories' information.

## Request

<figure><img src="../../../.gitbook/assets/image (2) (1).png" alt=""><figcaption></figcaption></figure>

### Header and Parameters Detail

**Ref. 01:** "AppKey" is the authorization key to authenticate with the API. This key must be valid and linked to an active ArqSign account.

**Ref. 02:** "idProcesso" - To retrieve the status of the process, the Process ID must be sent as a parameter. This ID is returned by the API as a successful response after calling the method: **POST​/api​/v1​/processo​/enviar-documento-para-assinar.**

Another way to obtain the Process ID is through the ArqSign platform, in the "History" option of the document available in the [Inbox](../../../mailbox/inbox.md), [Sent](../../../mailbox/sent.md), and [Deleted](../../../mailbox/deleted.md) boxes.

## Return

<figure><img src="../../../.gitbook/assets/image (1) (1) (1).png" alt=""><figcaption></figcaption></figure>

### Return Details

**Ref. 01 - Code 200:** As a successful response, the application will return code 200 along with the data of the process's signatories in JSON format.

**Ref. 02 - Code 400:** Mandatory Item Message: This message will be displayed in singular or plural when one or more mandatory items have not been sent in the API call.

**Ref. 03 - Code 400:** Incorrect Format Message: This message will be displayed in singular or plural when one or more items have been sent with an incorrect format.

**Ref. 04 - Code 400:** Non-Existing Ids Message: This message will be displayed in singular or plural when one or more Ids sent do not exist.

**Ref. 05 - Code 400:** Deleted Document Message: This message will be displayed when the process in question has been logically deleted.

**Ref. 06 - Code 400:** Incorrect or Non-Existent Parameter Message: This message will be displayed when the call is made with a wrongly written parameter or a parameter that does not exist in the method.

**Ref. 07 - Code 401:** Unauthorized API User Message: Invalid or not located AppKey.
