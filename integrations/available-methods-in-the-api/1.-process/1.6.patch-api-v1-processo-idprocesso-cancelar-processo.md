# ✔️ 1.6.PATCH/api/v1/processo/{idProcesso}/cancelar-processo

Objective: This method allows the user to cancel an ongoing signing process.

In this method, the user will send us the Process ID and we will cancel the specified process.

### Return Details

**Ref. 01 - Code 200:** As a successful return, the application will return code 200 along with the message "Document successfully canceled".

**Ref. 02 - Code 400:** Missing Required Item: This message will be displayed in singular or plural when one or more mandatory items were not sent in the API call.

**Ref. 03 - Code 400:** Incorrect Format: This message will be displayed in singular or plural when one or more items are sent with an incorrect format.

**Ref. 04 - Code 400:** Nonexistent IDs: This message will be displayed in singular or plural when one or more IDs sent do not exist.

**Ref. 05 - Code 400:** Document Deleted: This message will be displayed when the specified process has been logically deleted.

**Ref. 06 - Code 400:** Incorrect or Nonexistent Parameter: This message will appear when a call is made with a wrongly written parameter or a parameter that does not exist in the method.

**Ref. 07 - Code 422:** Validation Messages: These messages will be displayed when the user provides a process with a status other than "Waiting" or "In process."

**Ref. 08 - Code 401:** Unauthorized API User: AppKey is invalid or cannot be located.
